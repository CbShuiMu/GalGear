# 🌸 GalGear

**专注于GalGame的管理器，转区超分，补丁搜索管理，多数据源刮削，AI存档搜索。**

Windows x64 · 界面语言支持 简体中文 / 日本語 / English

GalGear 是一个 Windows 上的本地 Galgame 管理工具。把游戏目录加进来，就能看封面、找游戏、整理收藏夹、启动游戏，也能在同一个地方管理存档和补丁。

> 当前发行版为 **v0.4.7（2026-11-12）**。可从游戏详情重新匹配作品资料。改名后匹配到新词条时会同步封面、标签与资料。此版本也优化了首页背景加载，并补充了黑屏与界面无响应的诊断日志。

## 🚀 快速上手

前往 [Releases](https://github.com/CbShuiMu/GalGear/releases/latest) 下载 Windows x64 版本：

- **安装版**：下载 `GalGear_0.4.7_x64-setup.exe`，按提示安装。
- **便携版**：下载 `GalGear-0.4.7-win64-portable.zip`，解压后运行 `GalGear.exe`。

第一次打开，可以按这个顺序来：

首次启动时先选择界面语言。程序会按所选语言设置默认数据源，可在设置中更改。

1. 点击 **添加游戏库**，可一次选择多个存放游戏的文件夹。
2. 扫描后，在确认窗口选择资料来源和对应作品，启动程序可留到首次启动时再选。用 **批量修改** 统一来源，再点 **自动刮削** 查找候选。右下角显示进度与未匹配或失败数，可点 **停止刮削** 结束本轮。核对候选后再保存，已确认的条目会在再次刮削时跳过。
3. 打开游戏详情，检查启动配置，点击启动。（自动备份的开启需要启动游戏并进行一次存档）

### 🎮 Galgame管理

游戏可以放在不同目录，不必为了使用 GalGear 重新搬家。支持按名称搜索、组合标签筛选和排序，也可以用多层收藏夹整理正在玩、想玩或已经通关的作品。一款游戏能放进多个收藏夹，支持拖放和批量整理。

GalGear 会记录游玩时长和最近游玩时间。计时依赖 GalGear 对游戏进程的检测，玩游戏时请保持 GalGear 运行。

Waifu2x会在后台对封面去噪，并生成经过降噪的首页 4K 背景（保持原比例，长边 3840）。这项功能以 **笔记本 RTX 2060** 为最低配置设计目标，采用小分块、单任务处理；生成成功后才替换，相同封面会复用结果。部署与缓存说明见 [封面增强](docs/cover-enhancement.md)。

### 🏷️ TAG分类

从游戏的标签到游戏资料中的声优，所有属性都可以通过标签筛选。

### 🔎 多个数据源，自动刮削

作品资料可从 **2DFan、VNDB、Bangumi、月幕Gal、未萌NextMoe、KunGal** 中选择，每款游戏可以使用不同来源。简介、制作组、制作人员和标签会保存在本地，也可以自己修改。**感谢以上平台。**

封面可以单独按名称搜索、换来源挑选，或使用本地图片，不影响已经关联的作品资料。点击详情里的标签、制作组或制作人员，就能回到游戏库找相关作品。已经缓存的资料和本地游戏库可以离线浏览。  



界面支持粉色、白粉、白色三种主题色，可分别搭配亮色或夜间模式；语言和字号也能在设置中调整。

### 🔤 游戏内字体 Hook 与悬浮面板

游戏库中的游戏位于前台时，默认按 **Shift+T** 打开或隐藏 Rust 原生悬浮面板。可选择系统字体，调整高度、宽度、字距、行距和字重，并按需设置垂直度量、字符集伪装及日文旧字形/繁简映射。点击“应用到游戏”才加载与游戏进程同位数的 Hook；打开面板本身不会加载 Hook。参数按游戏保存，实际重绘和字体效果取决于引擎。快捷键可在“设置 → 路径与备份 → 存档备份与内置工具”中修改，点击卡片右上角保存后生效。

字体替换基于 [SuQiandYing 的 SimpleFontHook](https://github.com/SuQiandYing/SimpleFontHook)。GalGear 提供自己的悬浮面板、IPC、加载器和兼容补丁；上游及 Detours 的 MIT 版权与许可声明均原样保留，不改变这些组件的许可证。功能范围与兼容限制见 [游戏字体面板](docs/font-tools.md)。

### 📸 游戏截图

在游戏中按默认快捷键 **Shift+S** 截图后，图片会**自动复制到剪贴板**。切换到支持图片粘贴的聊天窗口、文档或图片编辑器，按 **Ctrl+V** 就能直接粘贴分享。

截图默认启用。可在“设置 → 路径与备份 → 存档备份与内置工具”中启用或停用截图、修改快捷键，并点击卡片右上角保存。快捷键仅在游戏库中的游戏位于前台时生效，游玩时需保持 GalGear 运行；与游戏自身快捷键冲突时，可以改用其他组合。

截图同时保存为**原尺寸无损 PNG**，普通窗口截取游戏画面，不包含标准标题栏和边框；使用 Magpie 时，可捕获超分后的画面，保留实际输出分辨率。图片按 UTC 时间命名，保存在游戏目录的 `screenshots/` 文件夹。

游戏详情页的“最近截图”卡片会显示最新图片，右上角可打开截图目录。卡片预览可能缩小，磁盘上的 PNG 保持原尺寸。若复制到剪贴板失败，已保存的图片仍会保留，可从截图目录中获取。

建议使用窗口或无边框模式，并让游戏画面完整显示在屏幕内；独占全屏、受保护画面或第三方覆盖层可能影响截图。管理员权限游戏可能需要一次 Windows 授权，以接收截图快捷键。

### ☁️ 云上存档/存档管理

GalGear 会寻找游戏目录、AppData 和“文档”等位置里的存档，也允许手动指定。  

确认位置后，可以备份多个存档目录、给备份写备注，或锁定一份不想被自动清理的记录。也可以按游戏开启退出后的自动备份。

恢复前会先展示预览，并备份当前存档。游戏正在运行时，请先退出再恢复或应用补丁。

在“设置 → 云存储”保存 **WebDAV** 连接后，退出游戏并点击详情页存档卡片的云上传图标。程序会先检查连接，再备份并上传存档。下载和恢复仍从云存储设置和本地历史发起。换电脑时，两边使用相同的游戏标题；有多个存档位置的，确认顺序也要一致。连接示例和具体步骤见 [云存储说明](docs/cloud-storage.md)。

云备份需要自己点击上传和下载，目前没有后台自动同步。

### 🧩 补丁搜索与管理

可以搜索 **2DFan、鲲 Gal、NextMoe** 的补丁资源，查看原站说明，下载网站提供的可用直链；也可以直接导入本地补丁。需要登录或付费的资源，仍受原站账号和权限限制。（**2DFan资源下载需要配置代理**）

可直接从游戏库选择作品来搜索补丁。“界面预览”中的补丁截图以库中的 **ATRI -My Dear Moments-** 为例，展示两个来源的补丁和存档结果。

本地 ZIP 可直接预览；RAR / 7z 使用随程序附带的 7-Zip。覆盖文件前会列出冲突并保留备份，之后可以恢复。EXE 补丁则使用它自己的安装流程。

已经解压的补丁，可以放进游戏目录的 `patch/` 下，每个补丁单独一个子文件夹。GalGear 会在详情页列出它们，方便安装或切换，不用每次手动复制。



### 📁 AI存档搜索

软件会先扫描一边预设的可能路径。AI存档搜索仅作为补充，新游戏使用该功能需要启动游戏并进行一次存档，退出后点击存档卡片右上角的AI搜索。



### 🤖 AI驱动剧情（测试中）

提供可选的 **AI 前情提要**。在“设置 → AI”配置 DeepSeek、OpenAI、Qwen 或 Kimi 的 API Token 和模型，再到游戏的编辑配置里开启 **AI 分析**。首次准备可能需要一些时间，完成后可以在详情页查看前情提要和当前进度。

另外还有 **AI 路线图**，会在默认浏览器里打开生成的分支与结局图。路线图固定使用 DeepSeek，需要另行配置 DeepSeek；它会分析完整台词，可能包含后续剧情和结局剧透。

这部分还在实验中，能否读取存档和脚本取决于具体游戏，无法保证每款都能用，生成的总结和路线也可能有误。启用时，分析所需的游戏台词、存档信息和作品资料会发给相应的 AI 服务，调用费用由你的 API 账号承担。更详细的用法见 [AI 设置](docs/ai-settings.md) 和 [前情提要说明](docs/ai-summary.md)。

## 🗂️ 数据存放位置

| 内容 | 保存位置 |
| --- | --- |
| 安装版 / 普通运行的配置和游戏列表 | `%APPDATA%/com.galgear.desktop` |
| 便携模式的配置和游戏列表 | 程序旁的 `data/`，由同目录下的 `portable.flag` 启用 |
| 存档备份 | 应用数据目录下的 `save-backups/<游戏名>/<YYYY-MM-DD-HH-mm>/`。在“设置 → 路径与备份”更改全局目录。同一分钟的多份备份追加 `-2`、`-3` 等编号。 |
| 游戏截图 | 游戏目录下的 `screenshots/`（原尺寸 PNG） |
| AI 准备文件和缓存 | 游戏目录下的 `.galgear-ai-summary/` |

便携版迁移时，一起带上程序目录和 `data/`，并带上自定义全局备份目录及程序旁的 `tools/`。启动后会在后台检查 GalGear 和 Skill 版本并显示待更新提示，不自动安装。Skill 不随发行包附带，请在“设置 → 更新 → Skill”点击“更新”安装。已安装的 `Galgear-GalgameReverse-Skill/` 可随程序迁移。

账号 Token、Cookie 和云存储密码保存在本机 Windows 凭据管理器中，换电脑后需要重新配置。从游戏库删除条目会永久清除条目资料、配置和游玩记录，需要重新导入；游戏、存档和备份文件会保留。路径暂时不可用时保留条目并显示红色提示，磁盘挂载变化会自动触发后台扫描。（2Dfan需自行抓取Token以及Cookie）



## 📌 使用须知

- GalGear 管理的是已经安装好的本地 EXE 游戏，不提供游戏本体，也不负责光盘镜像挂载或安装。
- 存档识别并不覆盖所有引擎，第一次备份前请检查位置。Locale Emulator、Magpie 可以在设置-路径与备份中修改配置路径，也取决于游戏与本机环境。
- 资源下载目前一次处理一个任务，暂不支持断点续传。

遇到问题，可以在 [Issues](https://github.com/CbShuiMu/GalGear/issues) 留下软件版本、出错步骤和报错信息。涉及存档或账号时，请先去掉个人信息。
