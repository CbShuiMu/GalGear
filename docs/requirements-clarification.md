# 首版剩余需求澄清

日期：2026-10-13。状态：已确认。原 Q1—Q22 与后续界面、资料及工具追加需求合并定稿。

产品基线为 [requirements.md](requirements.md)，实现与验收记录为 [implementation-status.md](implementation-status.md)。本文记录本轮已确认的决策和待讨论事项；待讨论内容不属于新增承诺。

## 已确认

- Q1：本轮聚焦补齐首版并满足公开发布条件。明确剩余功能与验收标准；首版之后的新功能单独记录。
- 原基线已确认的约束继续适用，除非用户明确修改。
- Q2：同版本在两个不同目录中的安装副本各自保留条目。每个条目最多对应一个安装目录，分别保留启动配置、标签及补丁记录。
- Q3：首版支持手动编辑名称、简介、开发商／发行商、发售日期及封面。按字段保护用户修改，重新获取资料仅更新未手动修改的字段。
- Q4：标签重命名的目标已存在时合并标签并去重。删除标签从所有游戏中解除该标签，操作前展示受影响游戏数量并确认。
- Q5：首版采用单任务下载，支持进度、取消及手动重试。退出后停止下载，重启无需恢复未完成任务；持久化下载队列与断点续传暂缓，不属于首版发布阻塞项。
- Q6：约 1,000 条目、固定测试机器及发行构建下，窗口可操作后 1 秒内展示缓存列表；扫描或联网期间搜索、滚动、切页响应不超过 200ms。扫描必须显示进度并可取消，总时长实测记录，暂不设统一门槛。
- Q7、Q13：不采用“同一作品”分组，版本间关联暂缓。不同版本独立保留，可用自定义标签整理。
- Q9：用户主动清空资料字段也属于手动编辑，保留空值；每个字段可单独恢复自动获取。
- Q10：标签去掉首尾空白，仅英文字母大小写不同的名称视为相同并去重。不同用词仍视为不同标签，不做同义词处理。
- Q11：ZIP 直接可用；RAR／7z 依赖本机 7-Zip。缺少工具时明确提示并提供安装入口，检测到工具后才允许预览和安装。
- Q12：运行状态识别配置启动程序对应的真实游戏进程，覆盖应用外启动及 GalGear 重启。外部启动工具自身的状态不能代替游戏状态；检测到运行时显示运行中并阻止重复启动，无法判断时显示未知。
- Q15：运行中或状态未知时禁止覆盖型补丁安装和恢复。状态未知时，普通游戏启动允许用户确认后继续；提供重新检测入口，只有明确未运行后才允许上述文件写入。原答复还涉及 CG 解锁，该功能安排已在 Q20 取消。
- Q16：取消、失败或重启时清理 GalGear 自己的未完成下载临时文件，保留完成文件。重启后通过本地补丁选择器重新选择下载文件；下载历史列表暂缓。重试重新检查资源及已购状态，不自动重复领取或扣费。
- Q18、Q21：游戏搬迁并重新定位后保留原身份、编辑和记录，处理扫描产生的重复条目；发现重复时展示差异并确认处理。补丁历史保留，恢复前重新确认目标并校验备份，无法确认时停止，不继续写入旧目录。保留失效或重复旧条目，允许用户手动从列表移除，保留游戏文件、存档及补丁备份；用红色感叹号或其他明显方式配文字提示。仅路径失效时显示“路径失效，可能已转移”，确认新位置后才显示“已转移”。
- Q19：提供排除项管理，可查看并取消排除，恢复时保留原编辑信息；这些操作不删除游戏文件。
- Q20、Q22：内置 CG／回想解锁整体退出首版，不发布 Angel Tear、AdvHD 等内置解锁能力；普通全 CG 存档补丁的搜索、下载和安装保留，继续走文件预览、冲突确认、备份和恢复流程，不承诺自动适配游戏版本。

## 事实核对

- 实现记录曾将持久化下载队列列为待完成，但原需求只要求进度、取消与失败重试。Q5 已明确队列暂缓，后续整合文档时应同步修正缺口清单。
- 当前自动扫描按目录路径生成身份并自动归组，手动添加按文件路径生成身份；尚无版本关系和用户合并建议模型。现状与需求目标分开记录，不将自动归组当作已满足确认合并。
- 当前资料手动编辑与保护主要覆盖名称，其他字段尚未完成完整编辑入口和逐字段保护。
- 游戏转移提示、手动删除对象、回想与存档补丁的范围已由 Q21、Q22 确定，未留下未回答的产品问题。
- RAR／7z 当前能在 PATH 和 ProgramFiles 下发现 7-Zip，缺失原因尚未完整本地化；发布包不含 7-Zip。
- 当前启动跟踪仅保存本次 GalGear 启动的直接子进程；运行状态界面及应用外进程检测尚未满足 Q12。
- 正常取消或失败会删除下载临时文件，崩溃后残留文件的启动清理尚未实现；最近下载文件仅保存在内存。
- 重新定位保留旧身份，但未检查目标条目冲突或记录扫描别名；补丁恢复仍使用安装时的绝对目标，存在恢复到旧目录的风险，需按 Q18 修正。
- 本次读取时仍见 CG 解锁界面动作和后端命令；Q20 是产品范围取消，不代表代码清理已经完成。既有 CG 验证只属于历史实现记录，不作为当前发布验收任务。

## 决策树与确认状态

- 首版公开发布范围（Q1）
  - 条目：不同安装副本独立（Q2）；不建作品分组、不做版本间关联（Q7、Q13）。
  - 用户数据：完整资料编辑（Q3）；清空与恢复自动获取（Q9）；标签合并、删除及命名规则（Q4、Q10）。
  - 运行与补丁：7-Zip 前提（Q11）；真实进程检测（Q12）；未知状态的启动与写入规则（Q15）。
  - 下载：单任务、队列及续传暂缓（Q5）；清理、重新选择文件与重试规则（Q16）。
  - 搬迁与排除：重新定位及补丁目标处理（Q18）；排除项恢复（Q19）；提示与手动移除范围（Q21）。
  - 能力取消：内置 CG 解锁取消（Q20）；回想整体退出首版，普通存档补丁保留（Q22）。
  - 性能：固定环境、发行构建、1,000 条目的 1 秒缓存与 200ms 交互门槛（Q6）。
