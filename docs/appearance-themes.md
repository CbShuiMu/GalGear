# 半透明主题与按钮

在“设置 → 显示与交互 → 主题颜色”选择粉色或白粉。主题色只在设置中更换，侧栏亮暗按钮只切换当前主题色的亮色／暗色模式，设置内也可直接选择亮暗模式。两项独立保存；切换亮暗保留主题色，更换主题色保留亮暗模式。原有亮暗配置继续使用粉色，上一版纯白配置迁移为白粉亮色。

原有粉色主题及其亮暗配色保留。白粉亮色以白色为主，使用珠白半透明面板、玫瑰粉边框、柔粉悬停色和少量粉色光晕；白粉夜间使用深灰紫背景、烟色半透明面板和柔和粉色高光。侧栏、设置卡片、阅读面板和弹窗使用透明叠加与背景模糊；弹窗的不透明度更高，保证叠加内容可读。状态提示保留原有语义颜色。

普通按钮采用两侧半圆的胶囊形状，左侧主导航和设置页左侧 Tabs 保留原有圆角。同一主题下，主要、次要、危险和导航按钮的常态背景、文字和边框颜色统一，悬停时统一切换另一组颜色。导航保留字重和标记，键盘焦点保留清晰轮廓，禁用按钮保留不透明度反馈。

各 Tabs 页移除重复的顶部标题；子收藏夹保留路径导航，补丁页账号入口并入搜索控件所在行。工具栏在两种亮色主题下均使用白色背景，夜间保留对应深色，普通和批量选择状态背景一致。

两种亮色主题的右侧主内容区及游戏详情背景统一使用纯白 `#fff`，移除该区域的背景渐变和粉色光晕。侧栏继续使用主题背景，夜间保留深色配色。

设置中的语言、主题色、亮暗模式、字号、默认资料来源、启动行为和关闭行为统一使用胶囊分段条。每组只有一块粉色选中背景，在选项间以 280ms 位移和宽度动画移动；首次显示和窗口尺寸变化时直接对齐。选项保留明确的按下状态，支持左右方向键、Home 和 End，减少动态效果偏好下不播放滑动。设置内切换主题色或亮暗时直接更新外观，让分段条滑动保持可见；侧栏亮暗按钮继续使用原有全页过渡。

下拉框保留原有形状和选项样式。游戏库卡片悬停时的收藏、通关、删除三个按钮保留原有圆角、透明背景、黄色／红色图标和悬停效果。海报、文件夹封面及卡片内标题属于内容入口，保留原有结构。

样式由 `web/appearance.css` 集中管理，放在既有布局样式之后加载。`data-theme` 只表示亮暗，`data-color-theme` 表示主题色。配置字段 `theme` 保存亮暗，新增 `color_theme` 保存主题色；Rust 命令分别修改各自字段，延迟返回的旧设置不会覆盖最新外观。DOM 桥接同步这两个属性并播放过渡，原生窗口外观仅随亮暗变化。构建脚本将新增样式复制到发行前端。
