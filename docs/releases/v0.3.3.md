# GalGear v0.3.3

发布日期：2026-11-01。Windows x64。

- 项目许可证改为 GPL-3.0-only；源码、安装包与便携包附带许可及版权说明，保留历史 MIT 声明和第三方许可。
- 新增游戏截图快捷键、最近截图预览和目录入口，支持 Magpie 缩放输出与管理员游戏的输入辅助。
- Skill 改为在“设置 → 更新”中手动检查和安装，启动时不再自动下载。
- 改进封面选择、目录打开、游戏详情和设置交互，新增英文、日文 README。
- 同步上游移除独立 Skill 目录的提交，清理旧发行包与临时验证产物。

安装版：`GalGear_0.3.3_x64-setup.exe`；便携版：`GalGear-0.3.3-win64-portable.zip`。附件校验值见 `SHA256SUMS.txt`。

需要 Windows 10 / 11 x64 和 Microsoft Edge WebView2 Runtime。便携版数据位于程序旁的 `data/`；保留 `tools/`。Skill 在设置中手动安装。

## 验证

Rust 工作区测试 551 项通过（10 项忽略），JavaScript/WASM 桥接测试 38 项通过，桌面全目标与 WASM Clippy 检查通过。全仓格式检查仍有既有差异，本次未批量格式化。

发布前端、AI 宿主和桌面程序重新构建。Windows 隔离便携目录启动、独立 AI 宿主解析检查通过。便携包检查 ZIP 完整性、主程序和许可文件一致性；安装包检查归档完整性及许可文件清单。

安装器实际安装、Windows 10 及全部游戏/缩放组合未纳入本次发行检查。
