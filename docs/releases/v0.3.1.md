# GalGear v0.3.1

发布日期：2026-10-31。Windows x64。

## 修复与改进

- 修复移除游戏、重启并移除游戏库后，重新添加同一目录只扫描、不显示“确认游戏资料与启动器”窗口的问题。重新添加目录时，该目录内原先移除的游戏会重新进入确认流程，保留已有资料和设置。
- 修复关闭确认窗口后，从空首页重新添加目录仍不显示窗口的问题。
- 修复 2DFan 账号测试成功但补丁下载连接失败的问题。文件下载遵循系统代理设置。
- 已存在确认的存档位置时，隐藏其他未确认候选项，覆盖自动识别和手动确认。
- 更新应用图标。

## 下载与运行

- 安装版：`GalGear_0.3.1_x64-setup.exe`。
- 便携版：`GalGear-0.3.1-win64-portable.zip`，完整解压后运行 `GalGear.exe`。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验值。

运行环境：Windows 10 / 11 x64、Microsoft Edge WebView2 Runtime。请保留程序旁的 `tools/`。便携版带有 `portable.flag`，数据保存在旁边的 `data/`；账号凭据由本机 Windows 凭据管理器保存。

## 验证

Rust 测试 505 项通过（另有 7 项跳过），JavaScript 测试 36 项通过，工作区 Clippy 检查通过。游戏库重新添加、2DFan 下载代理和已确认存档显示均有回归测试。两个用户反馈失败的 2DFan 翻译补丁已完成实际下载验证。

发布附件校验 SHA-256，便携包校验 ZIP 完整性和主程序一致性，NSIS 安装包完整性检查通过。安装器实际安装和 Windows 10 未纳入本次验证。
