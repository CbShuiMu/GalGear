# GalGear v0.2.1

发布日期：2026-10-29。Windows x64。

## 新增与改进

- 新增首页：按最近游玩时间浏览游戏，支持方向键、滚轮和标准手柄导航。
- 手柄可操作列表、弹窗和设置，并提供屏幕键盘。
- 新增白色主题与自定义背景，优化游戏详情和配置编辑。
- 新增封面增强，随包附带 waifu2x 运行文件。
- 扩展资料来源，新增 Qwen、Kimi AI 服务商选项。
- 改进游玩记录，支持游戏结束后的本地自动备份。
- AI 资源包更名为 `Galgear-GalgameReverse-Skill`；只有软件目录同时存在 AI 宿主和提取 skill，才允许开启 AI 功能。缺失时禁用开启与生成按钮并提示原因，已开启的选项仍可关闭。

## 下载与运行

- 安装版：`GalGear_0.2.1_x64-setup.exe`。
- 便携版：`GalGear-0.2.1-win64-portable.zip`，解压后运行 `GalGear.exe`。
- `SHA256SUMS.txt`：附件校验值。

需要 Microsoft Edge WebView2 Runtime。保留程序旁的 `tools/` 和 `Galgear-GalgameReverse-Skill/`，无需额外安装 Python。便携版带有 `portable.flag`，配置保存在旁边的 `data/`。账号凭据仍保存在本机 Windows 凭据管理器中。

AI 功能仍在测试，效果取决于游戏格式；分析会向所选 API 服务发送必要的游戏文本、存档信息及作品资料，并产生 API 费用。AI 路线图可能包含后续剧情与结局。WebDAV 上传下载需手动操作。

升级前保留已有配置及游戏存档。安装器实机安装、真实手柄和外部服务验收不包含在本次自动构建检查中。
