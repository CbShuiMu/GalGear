# GalGear v0.4.2

2026-11-08 · Windows x64 · GPL-3.0-only

- 悬停或聚焦游戏详情页的齿轮，展开转区、超分、自动备份和 AI 分析开关。快捷开关与完整配置同步，点击齿轮可打开完整配置。
- 存档卡片新增云上传入口。上传前先检查已保存的 WebDAV 配置和读写连接，再创建本地快照并上传。检查期间防止重复操作，连接失败时提示错误。
- 存档卡片用图标区分本地备份、历史和云上传。存档与截图卡片的目录按钮支持悬停和聚焦提示，多个存档目录可分别打开。
- 安装包和便携包随附 SimpleFontHook 和 Microsoft Detours 的完整 MIT 声明。

## 下载与使用

- 安装版 `GalGear_0.4.2_x64-setup.exe`
- 便携版 `GalGear-0.4.2-win64-portable.zip`，完整解压后运行 `GalGear.exe`，保留同目录的 `tools/`。
- 校验文件 `SHA256SUMS.txt`

需要 Windows 10 / 11 x64 和 Microsoft Edge WebView2 Runtime。云上传、下载与恢复步骤见 [备份与云存储说明](https://github.com/CbShuiMu/GalGear/blob/v0.4.2/docs/cloud-storage.md)。
