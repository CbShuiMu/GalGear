# GalGear v0.3.2

发布日期：2026-10-31。Windows x64。

## 新增与改进

- 支持导入 PotatoVN、ReinaManager 和 LunaBox 的游戏库备份，先预览再合并，跳过失效路径和重复条目。
- 支持导出 PotatoVN 格式的游戏资料、封面、收藏与游玩记录，不包含游戏、存档文件或账号凭据。
- 改进已验证数据源的选择与批量设置、2DFan 存档资源下载和安装。
- 支持选择 Magpie 缩放方案，优化工具设置、首页、封面选择和游戏库布局。
- 清理开发目录中的旧发行产物及临时验证文件。

## 下载与运行

- 安装版：`GalGear_0.3.2_x64-setup.exe`。
- 便携版：`GalGear-0.3.2-win64-portable.zip`，完整解压后运行 `GalGear.exe`。
- `SHA256SUMS.txt`：附件的 SHA-256 校验值。

需要 Windows 10 / 11 x64 和 Microsoft Edge WebView2 Runtime。保留程序旁的 `tools/`。便携版数据保存在旁边的 `data/`；账号凭据保存在本机 Windows 凭据管理器。Skills 启动时按需下载。

## 验证与边界

Rust 工作区测试 532 项通过（7 项跳过），JavaScript/WASM 桥接测试 36 项通过。桌面全目标与 WASM Clippy 检查通过。

发行前端、AI 宿主和桌面程序重新构建。Windows 隔离便携目录启动及独立 AI 宿主解析检查通过。便携包检查 ZIP 完整性及主程序哈希，安装包检查归档完整性。

`cargo fmt --all -- --check` 未通过，仓库已有格式差异（包括本轮未修改的 `catalog.rs`）；本次未批量格式化。

导入前保留源软件备份。PotatoVN 客户端端到端导入、安装器实际安装和 Windows 10 未纳入本次验证。
