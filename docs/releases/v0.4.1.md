# GalGear v0.4.1

2026-11-08 · Windows x64 · GPL-3.0-only

- 存档备份集中保存到可配置的全局目录，按游戏名和保存时间排列。旧目录中的备份校验后迁移，保留备注、锁定状态和恢复信息。
- 外接盘断开或路径不可用时保留游戏条目、收藏和游玩记录。磁盘挂载变化触发后台扫描。永久删除库条目会清除该条目的资料、配置和游玩记录，游戏文件和存档备份会保留。
- 游戏库支持按标题和别名搜索，资料、标签、封面和补丁入口可分别记住手动选择的数据源。详情支持就地编辑本地标签。
- 改进汉化启动器退出后对实际游戏进程的识别，用于游玩计时和退出后备份。首页跟随游戏库排序，详情按本地日期显示上次游玩时间。
- 安装包和便携包随附 SimpleFontHook 与 Microsoft Detours 的完整 MIT 声明。

## 下载与使用

- 安装版 `GalGear_0.4.1_x64-setup.exe`
- 便携版 `GalGear-0.4.1-win64-portable.zip`，完整解压后运行 `GalGear.exe`，保留同目录的 `tools/`。
- 校验文件 `SHA256SUMS.txt`

需要 Windows 10 / 11 x64 和 Microsoft Edge WebView2 Runtime。全局存档备份默认在应用数据目录下的 `save-backups/`。自定义位置和旧备份迁移见 [备份与云存储说明](https://github.com/CbShuiMu/GalGear/blob/v0.4.1/docs/cloud-storage.md)。
