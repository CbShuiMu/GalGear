# GalGear v0.2.0

发布日期：2026-10-26。Windows x64。

这次更新补上了游玩记录、云存档和 AI 前情提要，也整理了导入游戏、找封面和装补丁的流程。

## 新增与改进

- **游玩记录**：显示累计游玩时长和最近游玩时间。计时依赖游戏进程检测，游玩时请保持 GalGear 运行。
- **WebDAV 云备份**：手动上传当前存档、查看云端备份，再下载到本地备份历史中恢复。换电脑时，两边使用相同的游戏标题；有多个存档位置的，确认顺序也要一致。
- **AI 前情提要**：配置 DeepSeek 或 OpenAI 的 API Token 和模型后，可以为游戏开启 AI 分析，回顾之前的故事和当前进度。
- **AI 路线图**：根据游戏台词生成分支与结局图，在默认浏览器里查看。路线图固定使用 DeepSeek，需要配置对应的 API Token 和模型。
- **导入与资料整理**：在同一个窗口确认多款游戏的资料来源、作品词条和启动程序。封面支持单独搜索和更换；制作人员、制作组也能用于筛选相关作品。
- **本地补丁**：把解压好的补丁放入游戏目录的 `patch/`，每个补丁单独一个子文件夹，即可从详情页安装或切换。
- **页面状态保留**：切换设置或补丁页后，会保留本次运行中的输入、搜索结果和滚动位置。
- **存档备份位置**：备份统一保存在各游戏目录的 `.galgear-backups/saves/`，旧位置的历史会自动迁移。

## 下载与运行

| 附件 | 说明 |
| --- | --- |
| `GalGear_0.2.0_x64-setup.exe` | 安装版，按提示安装后启动。 |
| `GalGear-0.2.0-win64-portable.zip` | 便携版，完整解压后运行 `GalGear.exe`。 |
| `SHA256SUMS.txt` | 附件的 SHA-256 校验值，可用 PowerShell 的 `Get-FileHash <文件> -Algorithm SHA256` 核对。 |
| `build-info.json` | 本次发布的源码提交、构建工具及附件信息。 |

需要 Microsoft Edge WebView2 Runtime。安装包和便携包已附带 AI 运行文件，**无需另外安装 Python**。便携包中的 `skills/` 和 `tools/` 请一起保留，不要只复制主程序。

便携版的配置和游戏列表保存在程序旁的 `data/`。迁移时请移动整个程序目录，并保留游戏目录中的备份。账号 Token、Cookie 和云存储密码保存在本机 Windows 凭据管理器中，换电脑后需要重新配置。

仓库目前为私有，下载时需要登录有访问权限的 GitHub 账号。应用内更新检查尚不支持私有仓库认证，请手动前往 [Releases](https://github.com/CbShuiMu/GalGear/releases) 下载。

## 使用边界

- **AI 功能仍在实验中**，能否读取存档和脚本取决于具体游戏，生成的总结和路线也可能有误。首次准备可能需要较长时间。
- AI 分析所需的游戏台词、存档信息和作品资料会发送给相应的 AI 服务，**API 费用由你的账号承担**。路线图会分析完整台词，可能包含后续剧情和结局剧透。
- 云备份需要自己点击上传和下载，目前没有后台自动同步。下载只进入本地备份历史，检查恢复预览后才会应用到游戏存档。
- RAR / 7z 补丁需要本机安装 7-Zip；EXE 补丁使用它自己的安装流程。资源下载暂不支持断点续传。
- Windows 10 实机、安装器实际安装，以及真实 Locale Emulator / Magpie 组合仍需进一步验证。存档识别不覆盖所有引擎，第一次备份前请检查位置。

具体步骤见 [README](../../README.md)、[云存储说明](../cloud-storage.md)、[AI 设置](../ai-settings.md)和[前情提要说明](../ai-summary.md)。遇到问题，可以在 [Issues](https://github.com/CbShuiMu/GalGear/issues) 留下版本、操作步骤和报错信息。
