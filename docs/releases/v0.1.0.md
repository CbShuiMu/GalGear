# GalGear v0.1.0

发布日期：2026-10-15。Windows x64 首个 GitHub Release，仍在开发和验收中。

## 本版内容

- 本地 EXE 游戏库：多目录扫描、搜索、标签、收藏夹、批量整理与游戏启动。
- 关联 2DFan、VNDB、Bangumi、月幕 Galgame 资料；配置启动参数、Locale Emulator 和 Magpie。
- 存档位置检测、多位置快照、备份历史与恢复预览；补丁搜索、下载、本地预览、备份与恢复。
- 简体中文、日本語、English；粉色 / 白粉主题色与独立亮暗模式。
- 最新界面使用纯白亮色内容区、半透明面板、胶囊按钮及可键盘切换的分段设置；更新游戏、收藏夹、批量操作及设置图标。
- README 更新游戏库、详情、亮色设置与夜间设置四张截图，截图来自本次发行前端的隔离演示数据。

## 下载与运行

| 附件 | 说明 |
| --- | --- |
| `GalGear_0.1.0_x64-setup.exe` | NSIS 安装包。 |
| `GalGear-0.1.0-win64-portable.zip` | 解压后运行 `GalGear.exe`，包含 `portable.flag`、MIT 许可与使用说明。数据保存在旁边的 `data/`，迁移时移动整个目录。 |
| `GalGear.exe` | 独立程序；默认使用 `%APPDATA%/com.galgear.desktop` 保存数据。 |
| `SHA256SUMS.txt` | 附件的 SHA-256 校验值。PowerShell 可用 `Get-FileHash <文件> -Algorithm SHA256` 核对。 |
| `build-info.json` | 源码提交、构建工具与附件信息。 |

需要 Microsoft Edge WebView2 Runtime。便携包只包含程序及文档，不包含游戏、个人配置、存档或凭据。账号凭据由本机 Windows 凭据管理器保存，迁移后需重新配置。

仓库目前为私有库，下载需使用有访问权限的 GitHub 账号。应用内更新检查尚不支持私有仓库认证，请手动访问 [Releases](https://github.com/CbShuiMu/GalGear/releases)。
