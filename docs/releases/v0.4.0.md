# GalGear v0.4.0

发布日期：2026-11-07。Windows x64。GPL-3.0-only。

- 新增基于 SimpleFontHook 的游戏内字体 Hook 与 Rust 原生悬浮面板。游戏前台默认按 **Shift+T** 打开，选择字体、调整字号/字宽/字距/行距/字重，并配置垂直度量、字符集伪装与文字映射。
- 点击“应用到游戏”才加载与目标进程同位数的兼容组件；参数按游戏保存，实际字体与即时重绘效果取决于游戏引擎。独占全屏及小窗口存在显示限制。
- 字体 Hook 源自 **SuQiandYing / SimpleFontHook**，API 拦截使用 **Microsoft Detours**。安装包与便携包均原样保留两者的 MIT 版权/许可文本，GalGear 项目继续使用 GPL-3.0-only。
- 截图与字体面板共用前台窗口识别、Raw Input 和管理员输入辅助。截图默认 **Shift+S**，自动复制到剪贴板，可 **Ctrl+V** 粘贴。
- 新增程序旁 `logs/` 下的运行诊断，记录启动、命令、前端异常与原生故障线索，并对常见敏感字段脱敏；不自动上传日志。
- 快捷键支持按键录制、重置、取消与确认；字体面板、截图和 Magpie 的组合键统一校验，保存设置后生效。
- README 补充 Hook 与悬浮面板说明、上游致谢，为大标题添加 emoji，保留 GIF 预览及折叠布局。

## 下载与使用

- 安装版：`GalGear_0.4.0_x64-setup.exe`。
- 便携版：`GalGear-0.4.0-win64-portable.zip`，完整解压后运行 `GalGear.exe`，保留 `tools/`。
- 校验文件：`SHA256SUMS.txt`。

需要 Windows 10 / 11 x64 和 Microsoft Edge WebView2 Runtime。便携版配置在程序旁 `data/`，账号凭据由本机 Windows 凭据管理器保存。字体组件位于 `tools/font-hook/x86` 与 `x64`；首次使用时按需请求系统权限。

字体功能范围与限制见 [字体面板](https://github.com/CbShuiMu/GalGear/blob/main/docs/font-tools.md)，上游 MIT 原文见 [SimpleFontHook](https://github.com/CbShuiMu/GalGear/blob/main/docs/licenses/SuQiandYing-MIT.txt) 和 [Detours](https://github.com/CbShuiMu/GalGear/blob/main/docs/licenses/Detours-MIT.txt)，日志说明见 [运行日志](https://github.com/CbShuiMu/GalGear/blob/main/docs/runtime-logs.md)。

安装器实际安装、Windows 10 和全部真实游戏/引擎组合未纳入本次发行检查。Raw Input 隔离测试因测试窗口未获得前台焦点而失败，该次按键接收未完成验证。上游字体 Hook 的兼容性与即时刷新不能仅凭接口返回成功判定。
