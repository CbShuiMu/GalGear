# GalGear v0.3.0

发布日期：2026-10-30。Windows x64。

## 新增与改进

- 新增应用内版本检查和更新。下载时校验文件大小与 SHA-256，更新时保留用户配置、存档和工具设置，替换失败时回滚。
- 新增 AI 存档位置查找，改进存档识别、备份恢复和历史迁移。
- 改进补丁搜索、下载、解压和本地补丁文件夹管理，随包附带 7-Zip 26.05。
- 优化游戏库拖放、多选、收藏夹、筛选与工具栏布局，改进游玩时长显示和游戏配置。
- 改进 Magpie 与 Locale Emulator 的启动、退出和配置同步。
- 改进 AI 模型能力判断与 Skills 检查。Skills 不随包附带，启动时按上游 main 的 commit 检查并下载，失败时保留已有版本。

## 下载与运行

- 安装版：`GalGear_0.3.0_x64-setup.exe`。
- 便携版：`GalGear-0.3.0-win64-portable.zip`，完整解压后运行 `GalGear.exe`。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验值。

运行环境：Windows 10 / 11 x64、Microsoft Edge WebView2 Runtime。保留程序旁的 `tools/`，无需额外安装 Python 或 7-Zip。便携版带有 `portable.flag`，配置保存在旁边的 `data/`；账号凭据仍由本机 Windows 凭据管理器保存。

首次下载 Skills 需要联网及程序目录写入权限。AI 功能仍在测试，需要配置自己的 API Token；分析会发送必要的游戏文本、存档信息和作品资料并产生 API 费用，路线图可能包含剧透。WebDAV 上传下载需手动操作。
