# GalGear v0.3.4

发布日期：2026-11-04。Windows x64。GPL-3.0-only。

## 新增与改进

- NextMoe 成为新配置的默认资料源，封面选择器每次打开默认选中 NextMoe；仍可手动切换。
- 支持 NextMoe 联邦补丁搜索和托管文件下载。托管下载需要单独配置应用密钥，并具备运营授予的 `moyu:files` 权限；普通 OAuth 登录不能替代这项权限。
- Bangumi、NextMoe 使用内置应用进行浏览器 OAuth 授权，改进取消、回调、令牌刷新与旧凭据兼容。用户令牌保存在本机 Windows 凭据管理器。
- 改进下载进度、取消、错误反馈与文件落盘；NextMoe 下载不会刷新无关的 2DFan 账号。
- 修复存档候选路径、环境变量和 FHD/HD 名称匹配，按直属存档文件时间选择候选；手动指定位置优先保留。
- 首页背景使用封面模糊延展和方向过渡，优化快速切换、封面选择和明暗主题；游戏详情支持确认后删除本地标签。
- 启动后在后台检查 GalGear 和 Skill 版本，以“待更新”和数量提示展示结果；不自动安装，Skill 仍由用户点击“更新”安装。
- README 改为功能表格和集中式界面预览，默认显示两张截图，其余折叠。

## 下载与运行

- 安装版：`GalGear_0.3.4_x64-setup.exe`。
- 便携版：`GalGear-0.3.4-win64-portable.zip`，完整解压后运行 `GalGear.exe`。
- `SHA256SUMS.txt`：本次发行附件的 SHA-256 校验值。

需要 Windows 10 / 11 x64 和 Microsoft Edge WebView2 Runtime。请保留程序旁的 `tools/`；便携版数据位于旁边的 `data/`。默认截图快捷键为 **Shift+S**，图片会自动复制到剪贴板，可用 **Ctrl+V** 粘贴。已有配置保存的快捷键继续沿用。

OAuth 说明见 [回调服务](../oauth-callback.md)，AI 与存档搜索说明见 [AI 设置](../ai-settings.md)。源码与对应构建脚本随 v0.3.4 标签提供；第三方工具保留各自许可证。
