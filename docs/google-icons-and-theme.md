# Google 图标与亮暗主题

图标直接嵌入用户放入 src-tauri/icons 的 SVG，保留原始素材文件；显示时将固定填充色替换为 currentColor。补丁使用 extension。对应关系位于 crates/ui/src/icons.rs；没有对应素材的关于、箭头、语言、花朵品牌等继续使用原图标。

游戏、设置、文件夹、搜索、添加、刷新、关闭、播放、图片、确认、光盘、错误、备份、特殊文件夹和重新定位等使用对应 Google 图标。导航底部分组依次排列主题切换、设置、关于；主题按钮显示当前主题，亮色为日形“亮色”，暗色为月形“暗色”，点击后切换，支持键盘操作。

亮色保持原粉色视觉。暗色采用 #18141d 页面、#221c2a 阅读／表单区域、#ece5ef 主文字、#b5a5bb 辅助文字、#3c3046 分隔和粉色强调。主题保存到本机设置，旧配置默认亮色；恢复应用及切换主题时同步原生窗口主题，不修改系统设置。

过渡通过 DOM 桥接执行：支持 View Transitions 时从按钮位置展开新主题，520ms；不支持时以 480ms 淡入淡出旧画面并清理。动画偏好为减少动态时直接切换。首次启动恢复主题不播放切换动画，现有 CSP 保持不变。

Rust 保持主题状态、保存请求及错误处理。只有主题按钮在保存期间暂不可用，其余页面操作不因主题请求锁定；晚返回的旧偏好设置不会覆盖最新主题。

验证使用实际发行 Rust/WASM 与隔离传输夹具，在同一内容安全策略下检查图标、亮暗界面、动画、降级清理、延迟设置响应和窄屏布局。原有配置持久化测试增加暗色主题往返检查。实际验证结果及截图位于 artifacts/design/google-icons-*；这些浏览器截图不冒充原生窗口截图。

最终验证：65 项测试通过，全目标／全特性 Clippy、格式检查和 JavaScript 语法检查通过。双向动画确认 theme-reveal 520ms，回退 theme-fade 480ms 并清理；延迟语言设置没有覆盖新主题。680×540、18px 的五个导航按钮均为 63px，侧栏内容高度 540px，页面宽度 680px，无裁切或横向溢出。减少动态偏好下没有主题动画或残留层。

发行构建为 `artifacts/GalGear-icons-theme.exe`，构建及哈希记录为 artifacts/icons-theme-build.json。当前使用的旧 GalGear-next.exe 保留，请退出旧程序后使用新版。旧安装器和 ZIP 未重打包。
