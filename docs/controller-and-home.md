# 首页、主题与手柄操作

首页海报列显示所有已完成配置且未被排除的游戏。

首页沿用游戏库的排序字段和方向，默认按名称排列；可在游戏库排序选项中选择“最近游玩”，未玩过的游戏排在末尾，海报保持原始比例，选中描边位于封面外侧，留出 4px 透明间隙且不缩小封面；选中海报约放大至其他项的 1.5 倍。键盘左右方向键切换游戏，首页区域内滚轮向下切到右边、向上切到左边，持续滚动可连续切换，不设切换冷却时间；也保留手柄焦点操作。鼠标点击海报可选中对应游戏，悬停不改变选中项。切换时立即更新介绍，并平滑地将选中项对齐到海报列可见区域最左侧。背景等待新海报解码后，以约 440ms 的横向淡入淡出过渡：选择右侧游戏时，旧图向左淡出、新图从右侧淡入；向左选择时方向相反。快速连续切换只保留最新背景目标，当前动画结束后跳过中间项，最终显示最后选中的游戏；无封面或加载失败时淡出到页面底色。最后一项同样可以靠左，调整窗口尺寸后仍保持对齐；系统减少动态效果时直接完成切换。

竖封面背景与窗口等高、贴右显示，以全幅模糊延展、与原图对齐的模糊层及清晰原图逐层衔接；清晰层渐隐的结束位置由原图宽度的 44% 微调到 38%，使模糊过渡稍向左移；横封面铺满背景。首页不加载用户自定义背景，其他页面仍使用保存的背景设置。海报列直接置于顶部，不显示额外游戏库入口、滚动条、页首标题、故事提示或手柄提示。可启动游戏、打开详情、管理收藏或切换通关状态。首页和详情按收藏、通关排列图标，复用游戏卡片悬停区样式；详情图标放在游戏配置按钮右侧，首页紧随其后显示“最近游玩 {上次启动日期}”，未玩过时显示“尚未游玩”。已通关的游戏卡片在非悬停状态右上角显示黄色实心奖杯，悬停或键盘聚焦时隐藏。完整游戏列表从侧边栏的游戏库入口进入。

设置的外观选项新增「白色」配色，独立于原有粉色、白粉配色，并可搭配亮色或暗色模式。

资料、标签和封面选择器默认跟随设置中的“默认数据源”，各入口手动选择后保留该偏好（重启仍有效），不修改游戏已有资料关联。鲲Gal仅为显示名称，接口仍使用 NextMoe。

首页导航使用提供的 `home_24dp_1F1F1F_FILL0_wght400_GRAD0_opsz24.svg` 图标。首页与详情页的启动按钮共用 `game-launch-button` 样式，保持相同的尺寸、胶囊圆角、配色、文字排版及悬停效果。

连接系统识别为标准映射的手柄后，在应用窗口内使用：

| 操作 | 按键 |
| --- | --- |
| 按空间位置移动焦点 | 方向键 / 左摇杆 |
| 确认、点击、切换选项 | A |
| 关闭当前菜单、弹窗或返回详情上一层 | B |
| 按控件顺序移动焦点 | LB / RB |
| 滚动当前页面或弹窗 | 右摇杆 |
| 调整已聚焦的滑块 | LT / RT |

聚焦文本框后按 A 打开屏幕键盘，可输入拉丁字母、数字、路径符号和常用标点；中文、日文等输入仍可使用系统输入法。屏幕键盘的「完成」提交修改，B 或「取消」保留原值。原生系统文件选择窗口由操作系统负责输入。

在游戏详情的「编辑配置」顶部勾选「自动备份」即可保存开关。确认存档目录后，保持 GalGear 运行；检测到游戏从运行变为已停止时，复用现有快照流程执行一次本地备份。无法确定进程状态时不会提前备份。此选项不启用 WebDAV 自动上传。

详情页的配置齿轮在悬停或键盘／手柄聚焦时顺时针旋转，向右展开胶囊并推开收藏、通关按钮；点击齿轮仍打开完整配置。展开区依次为青色 LE（转区）、绿色 M（超分）、粉色备份图标、蓝色 AI（AI分析）。圆形按钮的悬停底色跟随主题，开启时显示彩色描边；四个快捷开关与配置弹窗共用状态和可用条件，保存成功后同步，失败保留原状态。触屏常显快捷开关，减少动态效果时直接展开；窄窗口中工具栏独占一行，避免展开时换行抖动。

截图卡片与存档卡片使用带文字提示的 `folder_open` 图标打开目录。存档目录入口位于卡片右上角「手动指定」右侧；多个有效目录分别提供入口，提示中显示路径，没有有效目录时禁用入口。

实现分工：

- `crates/ui/src/home.rs`：首页游戏排序、选中项和渲染。
- `web/home.js`：方向键/滚轮切换及海报列的平滑对齐；使用稳定 DOM 节点保持缩放动画连续。
- `web/home-backdrop.js`：海报预加载、方向识别及背景图层的淡入淡出；过期加载结果和离开首页后的回调不再更新背景。
- `crates/ui/src/game_actions.rs`：首页、卡片、详情共用的收藏与通关控件。
- `crates/ui/src/detail_tools.rs`：详情快捷开关与完整配置选项的共享状态和渲染。
- `web/navigation.js`：弹窗边界、可聚焦控件和焦点移动。
- `web/gamepad.js`：标准手柄输入、方向重复、屏幕键盘。
- `crates/core/src/play_sessions.rs`：不依赖 Tauri 的游玩结束检测；桌面层负责调用快照服务。

## 详情标签删除

详情顶部按品牌、发售日期、游玩时间、上次游玩的顺序显示四列资料，每列标题在上、内容在下，窄窗口换为两列；缺失资料显示“未设置”，品牌文字仍可点击筛选。上次游玩按系统本地日历计算：今天、昨天、前天优先，其余本周显示“周几”，上周显示“上周几”，上上周及更早显示日期；周一为一周起点，未来日期也显示绝对日期。日期判断保留在 Rust，JavaScript 只提供本地日期和今天，不按固定 24 小时计算天数。

详情标签区域不显示标题，末尾依次放置添加标签和更换标签源的胶囊图标按钮；数据库图标仍打开既有标签源选择窗口。游戏资料卡片隐藏故事、制作与发行的分节标题，右上角三个操作及补丁目录入口使用带文字提示的图标按钮。

详情页卡片内的操作按钮在悬停或焦点进入对应卡片时，从上方淡入落位，离开后上移淡出，保持原有布局占位；资料标签始终可见。键盘和手柄仍可聚焦这些按钮，触屏常显，系统减少动态效果时不播放过渡。首页和游戏库的路径失效感叹号使用透明背景。

详情顶部的本地标签支持悬停或键盘聚焦展开右侧圆角，并淡入仅含 × 图标的删除按钮；触屏设备始终显示该按钮。点击标签文字仍进入游戏库筛选，游戏资料中的标签不提供此删除入口。删除前显示确认弹窗，取消和确认按钮位于右下角；Escape 或手柄 B 取消并恢复焦点。保存成功后才更新标签列表，失败时保留原标签并提示错误；沿用逐游戏标签删除规则，资料刷新不会重新加入已删除名称。系统减少动态效果时直接展开按钮。

标签悬停或键盘聚焦时，左侧同样展开编辑图标。点击后在原标签内编辑；末尾的“+”胶囊用于输入新标签。输入框自动聚焦、随文字变宽，Enter 保存，Escape 或右侧 × 取消输入，中文输入法选词时不提交。增改使用同一逐游戏标签规则，成功响应前保留草稿，失败时可继续修改重试。

鼠标与键盘模式下，编辑、删除按钮通过绝对定位向两侧展开，不改变标签在 flex 行内的尺寸；标签左边界（收起状态）与启动按钮对齐，编辑按钮向左侧留白展开，右侧保留 28px 删除操作空间，避免行尾标签展开后换行、失去 hover 再缩回的循环。触屏模式保持按钮常显并参与正常排版；减少动态效果时关闭过渡。
