# 首页、主题与手柄操作

首页按最近游玩时间排列游戏，海报保持原始比例，选中描边位于封面外侧，留出 4px 透明间隙且不缩小封面；选中海报约放大至其他项的 1.5 倍。键盘左右方向键切换游戏，首页区域内滚轮向下切到右边、向上切到左边，持续滚动可连续切换，不设切换冷却时间；也保留手柄焦点操作。鼠标悬停或点击海报不改变选中项。切换时同步更新背景和介绍，并平滑地将选中项对齐到海报列可见区域最左侧。最后一项同样可以靠左，调整窗口尺寸后仍保持对齐；系统减少动态效果时直接完成切换。

竖封面背景与窗口等高、贴右显示，以全幅模糊延展、与原图对齐的模糊层及清晰原图逐层衔接；横封面铺满背景。首页不加载用户自定义背景，其他页面仍使用保存的背景设置。海报列直接置于顶部，不显示额外游戏库入口、滚动条、页首标题、故事提示或手柄提示。可启动游戏、打开详情、管理收藏或切换通关状态。首页和详情按通关、收藏排列图标，复用游戏卡片悬停区样式；首页的游玩时间紧随其后。完整游戏列表从侧边栏的游戏库入口进入。

设置的外观选项新增「白色」配色，独立于原有粉色、白粉配色，并可搭配亮色或暗色模式。

首页导航使用提供的 `edit_24dp_1F1F1F_FILL0_wght400_GRAD0_opsz24.svg` 图标。首页与详情页的启动按钮共用 `game-launch-button` 样式，保持相同的尺寸、胶囊圆角、配色、文字排版及悬停效果。

连接系统识别为标准映射的手柄后，在应用窗口内使用：

| 操作 | 按键 |
| --- | --- |
| 按空间位置移动焦点 | 方向键 / 左摇杆 |
| 确认、点击、切换选项 | A |
| 关闭当前菜单、弹窗或返回详情上一层 | B |
| 按控件顺序移动焦点 | LB / RB |
| 滚动当前页面或弹窗 | 右摇杆 |
| 调整已聚焦的滑块 | LT / RT |

聚焦文本框后按 A 打开屏幕键盘，可输入拉丁字母、数字、路径符号和常用标点；中文、日文等输入仍可使用系统输入法。屏幕键盘的「完成」提交修改，B 或「取消」保留原值。原生系统文件选择窗口由操作系统负责输入。

在游戏详情的「编辑配置」顶部勾选「自动备份」即可保存开关。确认存档目录后，保持 GalGear 运行；检测到游戏从运行变为已停止时，复用现有快照流程执行一次本地备份。无法确定进程状态时不会提前备份。此选项不启用 WebDAV 自动上传。

实现分工：

- `crates/ui/src/home.rs`：首页游戏排序、选中项和渲染。
- `web/home.js`：封面方向识别、方向键/滚轮切换及海报列的平滑对齐；使用稳定 DOM 节点保持缩放动画连续。
- `crates/ui/src/game_actions.rs`：首页、卡片、详情共用的收藏与通关控件。
- `web/navigation.js`：弹窗边界、可聚焦控件和焦点移动。
- `web/gamepad.js`：标准手柄输入、方向重复、屏幕键盘。
- `crates/core/src/play_sessions.rs`：不依赖 Tauri 的游玩结束检测；桌面层负责调用快照服务。
