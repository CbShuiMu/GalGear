# Rust 实现与复审（2026-10-13）

按 rust-best-practices 的所有权、错误传播、静态分派、线程安全和测试原则实施本轮变更。需求以 requirements.md 为准；本记录区分代码实现和真实验收。

## 本轮新增实现

- 新详情采用大封面、可确认／取消的内联标题、标题右侧标签、2:1 故事及辅助区域；窄窗口改单列，故事自然滚动。取消、Esc、点击编辑区外放弃标题草稿；无效标题或保存失败保持输入和编辑状态。
- 添加菜单合并游戏库／游戏；启动菜单提供普通／转区启动和按游戏保存的默认方式，超分独立。
- 共用封面倍率 50%—200%，预设 90%／100%／120%，Alt＋滚轮每次 5%；字体 14／16／18px，设置持久保存。
- 扩展品牌、开发商、发行商、发售日期、原画、声优、剧本、音乐、歌手及人物／品牌链接。品牌不推断为开发商；缺少真实故事不使用 SEO 摘要。资料逐字段手动修改、主动清空、恢复自动值；封面可取消手动覆盖而保留原图片。
- 网站 TAG 合入本地标签，只补新名称；本地删除／改名规则持久保存。支持统一重命名合并、删除前展示受影响数量、重置规则。详情标签返回库筛选并清空搜索、保留排序。
- 存档确认区分配置／引擎证据和名称候选，保留多个确认位置。快照包含所有确认位置，默认保存到应用数据旁的 save-backups，可配置目录／保留数量，支持备注、锁定、删除、文件浏览。
- 恢复使用当前确认位置，预览新增／覆盖／移除，先备份当前状态，再替换完整存档树。校验快照内容和预览后的外部修改；失败回滚；中断日志在运行状态和当前位置明确时恢复，不满足条件时保留并提示。
- 默认关闭的退出后自动备份只在应用运行时执行。识别真实配置程序，使用一轮系统进程快照检查整库，覆盖应用外启动和应用重启；未知状态禁止存档及覆盖补丁写入。
- Locale Emulator 使用官方 `-runas GUID executable args` 形式，从用户 LEConfig.xml 选择日文非管理员配置，允许指定其他现有配置，不改全局区域。Magpie 检查已有实例、定位真实游戏窗口、切到前台并发送用户已配置的快捷键，仅声明触发，效果未确认。

## 复审修正

| 旧问题 | 修正 |
| --- | --- |
| 故事缺失时用网站通用摘要填充 | 只读主体故事容器，保留段落，缺失时明确显示暂无介绍。 |
| 品牌直接作为 developer | 分开缓存 brand／developer／publisher，完整保留人员名单和原站链接。 |
| 修改标签和启动配置可能意外覆盖资料／名称 | 标签独立命令；编辑名称未变化时保留原保护状态；后台获取继续保护手动字段和主动清空。 |
| 标签大小写去重不统一，刷新会复活已删除名称 | ASCII 大小写归一、首尾去空白，记录删除／重命名规则，并处理连续重命名。 |
| 只跟踪 Child，外部工具可被误当游戏进程 | 以完整真实程序路径检测，权限不足或程序不存在为未知，不以工具进程代替。 |
| 补丁中断恢复不校验运行状态或搬迁目标 | 重新检查真实运行状态及当前游戏／确认存档目标；不满足条件停止并保留备份。 |
| 解锁入口仍可调用 | 删除桌面安装命令、详情及关于页入口；扫描不再执行解锁分析。历史实验源码保留，不随桌面界面发布。 |
| 扫描错误可能使运行标志永久占用 | RAII guard 覆盖整个扫描及落盘阶段，错误路径自动释放。 |
| 首次启动硬编码开发者 F:\\GALGame | 移除此默认目录，公开软件不推断用户游戏库。 |
| 同秒备份依靠随机 ID 排序，可能误删最新备份 | ID 使用纳秒时间排序；内容落盘并验证成功后才清理历史，锁定备份保留。 |
| Windows 签到测试的本地 socket 偶发 WouldBlock | 已接受的 socket 显式切为阻塞模式，保留超时和交易断言。 |

## 验证与边界

- 原有及新增测试涵盖资料段落／字段／链接／TAG 容器、手动清空保护、真实可执行程序检测、日文配置读取、快照完整恢复、外部变化、损坏内容、保留锁定、运行状态和中断回滚。最终命令结果见 implementation-status.md。
- 真实 Rust/WASM 隔离传输夹具验证标题失败保留输入／成功退出、备份及恢复确认参数。夹具没有写入实际游戏存档。
- 1360×900 与 680×540，分别检查 16px／100%、14px／50%、18px／200%，六组无横向溢出、导航文字未裁切；宽屏正文 2:1，窄屏单列。测量记录在 artifacts/design/new-implementation-*-measurements.json。
- 当前应用外真实进程检测通过 Windows 测试；尚未在用户实际游戏、Locale Emulator 和 Magpie 组合中验证区域效果、启动参数优先级及缩放效果。代码接通不等于这些真实验收已经通过。
- 历史首版缺口（镜像／安装确认关联、重新定位重复条目差异、排除项恢复管理、搬迁后的补丁显式重新绑定、RAR／Windows 10／安装器等）仍需逐项处理，未把此次复审描述为整个首版全部完成。
- 旧版 GalGear.exe 正在运行，本轮输出独立 GalGear-next.exe。旧安装器／ZIP 不据此宣称已经升级，退出旧应用后运行新 EXE 才会使用本轮代码。

外部工具依据：[Locale Emulator 官方调用代码](https://github.com/xupefei/Locale-Emulator/blob/master/LEProc/Program.cs)、[官方配置格式](https://github.com/xupefei/Locale-Emulator/blob/master/LECommonLibrary/LEConfig.cs)、[Magpie 官方项目](https://github.com/Blinue/Magpie)。

最终验证：65 项测试通过（core 58、i18n 2、ui 1、桌面 4），全目标／全特性 Clippy 和格式检查通过。内容安全策略保持原配置，显示变量由 DOM 桥接写入；使用同一策略的发行 WASM 夹具复测通过。详情面板与游戏页面主区域同宽。
