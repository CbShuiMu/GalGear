# 新界面设计提案

日期：2026-10-14。状态：以用户最新图 1 为最高优先级的详情设计方案。布局、标签卡片、字号与封面规则已逐项明确，本轮与需求整合稿一并定稿。关联 [新增需求访谈](ui-and-tools-requirements.md)。

## 设计方向

保留 GalGear 的粉色视觉，以游戏封面、大标题和连贯的故事阅读区作为详情的中心。导航与工具操作让出空间；资料区有明显主次，编辑和文件位置位于辅助区域。

## 颜色与字体

沿用现有颜色，避免主题变更干扰本次结构调整：

| 角色 | 色值 |
| --- | --- |
| 页面底色 | #FBF7FA |
| 阅读区底色 | #FFFFFF |
| 主要操作与选中态 | #D75C95 |
| 正文 | #302A35 |
| 辅助文字 | #918490 |
| 分隔与边框 | #EEE5ED |

字体使用 Windows 本地字体：Segoe UI Variable／Segoe UI 承担西文，Microsoft YaHei UI 承担中文，日文采用可用的系统字体回退。字体基准三档 14／16／18px，16px 默认；标题、正文与辅助文本保持层级，文字左对齐，故事行长与行距适合阅读，避免固定高度的局部滚动。

## 已确认的基础布局

侧栏采用纵向排列的窄导航，每个导航项图标在上、文字在下，保持粉色选中态。宽屏详情以 2026-10-14 图 1 为准，标签放在头部按钮下方：

```text
┌──────────────────────────────────────────────────────┐
│ 大封面 │ 可编辑游戏标题                               │
│        │ 启动及相关工具操作                           │
├──────────────────────────────────┬───────────────────┤
│ 故事介绍                         │ 编辑配置          │
│ 2DFan 资料与制作人员             │ 游戏位置          │
│ 主要阅读区，约占 2/3             │ 存档位置          │
│                                  │ 请支持正版        │
│                                  │ DLsite 官网入口   │
└──────────────────────────────────┴───────────────────┘
```

窄窗口采用同一信息顺序的单列布局，编辑与游戏位置相邻；故事随页面自然滚动。封面采用当前窗口的自适应基准乘用户百分比，100% 为基准、输入 50%—200%；具体尺寸公式属于后续实现与布局验证，不是未回答的产品问题。

## 对照需求的审视

重点改动是腾出故事阅读空间和让封面随窗口适度增长，保留游戏封面自身的视觉辨识度。当前“资料、位置、存档、CG 各占同等卡片”的层级无法突出故事，应调整为一个主要阅读区和辅助操作区；与用户明确要求的粉色风格保持一致。

大字号与小窗口通过换行、改单列及自然纵向滚动容纳内容，保持主要故事区的阅读层级。设计方案已与最终需求合并定稿，应用实现及真实验收另行进行。
