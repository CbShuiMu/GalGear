# WebDAV 云存储

GalGear 在「设置 → 云存储」中配置 WebDAV，按游戏手动上传当前存档、浏览云端快照及下载到本地备份历史。下载完成后，再通过已有的恢复预览与确认流程恢复存档。

本地备份历史统一保存在全局备份目录，默认位置为应用数据目录下的 `save-backups/`，可在“设置 → 路径与备份”更改。每个游戏按名称分目录，快照目录和显示名称采用本地保存时间 `YYYY-MM-DD-HH-mm`，同一分钟的多份备份追加 `-2`、`-3` 等编号。非法文件名字符会被替换，长标题最多保留 64 个字符，同名游戏分配独立目录。游戏改名后沿用已登记的备份目录。

手动备份、自动备份、上传前快照和云端下载共用此位置。旧游戏目录中的 `.galgear-backups/saves/`、旧全局 ID 目录及之前选择的备份目录会在内容校验后迁移，保留备注、锁定、编号和恢复事务。离线位置会在再次可访问并读取该游戏备份时继续迁移。更改目录先复制并校验已知全局历史，再保存设置，旧副本随后按游戏校验清理。

远端快照身份由完整快照计算，避免不同设备同一分钟的本地名称冲突；下载后使用本地时间名称保存。

## 配置连接

| 字段 | 填写内容 |
| --- | --- |
| WebDAV 地址 | 服务商提供的完整 WebDAV 入口，包含 `https://` 与入口路径。 |
| 用户名 | 服务商提供的 WebDAV 用户名。 |
| 应用密码 | WebDAV 专用密码或应用授权密码。 |
| 远端目录 | WebDAV 入口下用于存放 GalGear 备份的目录，建议保留默认值 `GalGear`。 |

填写后先「测试连接」，再保存配置。测试使用当前表单内容，会创建远端目录，并上传、删除一个临时空文件以验证读写权限；测试不会自动保存配置。已经保存密码时，同一服务器及用户名可以留空密码输入框以沿用原密码；更换服务器或用户名需要重新输入密码。「清除连接」移除本机连接与密码，不删除云端备份。

地址与用户名保存在本机设置，密码保存在 Windows 凭据管理器，不写入 `settings.json`。移动便携版或迁移到另一台电脑后，需要重新配置密码。云端快照包含存档文件；GalGear 不对存档额外加密。

### 坚果云

1. 登录坚果云，进入「账户信息 → 安全选项 → 第三方应用管理」，为 GalGear 生成应用密码。
2. WebDAV 地址填写 `https://dav.jianguoyun.com/dav/`，用户名填写坚果云账号邮箱，密码填写刚生成的应用密码。
3. 测试连接并保存。

官方说明：[生成第三方应用密码](https://help.jianguoyun.com/?p=2064)、[WebDAV 地址及账号示例](https://help.jianguoyun.com/?p=5677)。

### 123 云盘

登录 [123 云盘官网](https://www.123pan.com/)，在官方 WebDAV 授权管理中取得当前账号的服务器地址、用户名和应用密码，并确保授权目录允许读写。将官方页面提供的信息填写到 GalGear；服务器地址以账号页面当前显示为准。若只授权了某个文件夹，远端目录应填写相对于该授权入口的路径。

123 官网介绍了 WebDAV 挂载能力。本功能通过通用 WebDAV 协议连接，不使用 123 私有 API；可用权限、容量和流量以服务商账号页面为准。

## 上传和恢复

1. 在游戏详情确认全部存档位置，并退出游戏。
2. 点击游戏详情存档卡片中「历史存档」右侧的云上传图标；程序先检查已保存的连接信息和凭据，再测试 WebDAV 读写连接，通过后创建并校验本地快照并上传。缺少配置时进入「设置 → 云存储」，连接测试失败则停止上传并提示错误。也可在云存储设置的「存档同步」中选择本地游戏，点击「上传当前存档」。连接表单有未保存修改时，需要先保存才能同步。
3. 在另一台电脑保存相同的云存储连接，选择对应的本地游戏，刷新云端快照列表，选择快照并下载。
4. 下载完成后，通过「打开游戏备份历史」进入对应游戏详情，在本地备份历史中选择该快照，检查恢复预览，再确认恢复。

云端按游戏标题分组，与游戏安装路径无关。不同设备应使用相同标题；标题前后的空格及大小写会忽略。修改标题会切换云端分组，同标题的不同版本会共享一个分组。多个存档位置在恢复时按确认顺序对应，应在各设备以相同顺序确认相同用途的位置。上传时将绝对存档路径替换为编号标签，旧设备路径不会成为恢复目标。

详情存档卡片依次使用 `backup`、`history`、`cloud_upload` 图标表示本地备份、历史存档和云上传，悬停或键盘聚焦可查看文字提示。检查连接和上传期间禁用重复操作；连接检查完成前离开原游戏会取消后续上传。上传请求发出后继续处理原游戏结果，并在仍查看该游戏时刷新本地历史（上传失败也可能已经产生本地快照）。

上传期间检测到游戏正在运行、运行状态无法确认、存档发生变化或目录不安全时，操作会停止。下载只导入本地备份历史，不直接覆盖正在使用的存档。恢复仍检查游戏运行状态和预览后的文件变化，并按现有规则创建恢复前备份。

## 使用边界

- 同步由用户手动触发；没有后台自动同步、实时双向合并或自动冲突覆盖。
- 每次上传保留独立快照。网络上传失败时，已经创建的本地备份仍可在历史中使用；重试上传会创建新的快照。
- 本地备份保留数量不自动清理云端历史。需要释放云空间时，可通过服务商的文件管理界面处理。
- 每份云端快照由 ZIP 存档和 JSON 完成标记组成，下载会校验归档及每个存档文件的大小与 SHA-256。归档上限为 500 MiB，未压缩存档总量上限为 2 GiB，文件数量上限为 20,000，每个游戏的云端列表最多读取 300 份快照。超过上限时需先通过服务商管理云端历史；清理时应一起处理同名 `.zip` 与 `.json` 文件。
- 使用 HTTPS 地址连接公网服务。账号验证失败时，优先检查应用密码、授权目录及读写权限；限流时等待后重试。
- 坚果云官方说明存在上传大小、请求频率与单次目录列表数量限制。大量历史可能受到服务商列表截断影响；GalGear 不实现服务商私有分页扩展。具体限制见[官方第三方应用访问说明](https://help.jianguoyun.com/?p=2064)。
- 123 与坚果云的说明依据官方页面核对；没有使用真实服务商账号完成上传下载验收。
