# 本地标签统一且不保留来源

2026-10-13 新增需求访谈 Q32 中，用户明确选择将网站导入和手动编辑的标签作为统一本地标签使用，不保留 TAG 来源，取代此前带来源的提案。标签继续参与同一套展示、编辑和筛选。

带来源的模型有利于区分外站增删与人工修改，但本次选择不保留该信息；后续不能从既有标签准确反推出来源，也不能将人物／品牌链接当作游戏标签来源回填。

Q42 已确认采用本地编辑规则：首次导入，后续只补新名称，不因网站移除而自动删除本地标签；用户删除或改名的旧名称不自动重新加入，可重置规则。保存这些名称编辑规则不代表恢复来源分类，不向原站提交修改。

这项决策只针对游戏 TAG，不取消游戏与 2DFan 资料条目的关联，也不取消品牌及制作人员资料中原站提供的链接。
