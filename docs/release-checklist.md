# 首版发布验收清单

日期：2026-10-13。对应已定稿的 [requirements.md](requirements.md)。发布范围：Windows 10／11 x64、安装版与便携版、中文／日文／英文。本清单确认的是验收目标，不表示实际验收通过。

2026-10-15 发布补充：`v0.1.0` 提供 GitHub Release、重新构建的独立 EXE、便携包及 NSIS 安装包。本次 97 项测试、桌面及 WASM Clippy、格式检查通过，完成最新发行前端截图、README 宽窄布局和隔离便携目录的 Windows 原生启动检查。安装器实际安装、Windows 10 及真实游戏／外部工具组合仍待验收，下表保留历史记录，不能视作本次全部通过。详情见 [v0.1.0 发布说明](releases/v0.1.0.md)。

## 验收记录方式

- 每项记录发行版本、构建标识、运行环境、操作步骤、结果和证据路径；失败或未执行保持明确状态。
- 性能记录机器配置、系统、游戏库所在存储及样本结构、构建类型、测量起止点、缓存展示时间、交互响应和扫描时长。本地交互响应与外站请求完成时间分别记录。
- 搬迁、备份、恢复、取消和强制中断场景在可恢复的测试游戏副本或临时目录中验证；确认游戏、存档和备份均符合保留要求。
- 原始历史验证不改写为新发行包结果；新结果同步回 implementation-status.md 和本清单。
- 存档只纳入该游戏的存档范围，避免将游戏本体或用户文档根目录加入快照；恢复、保留清理和共享存档位置的运行约束需用独立副本检验。

## 不阻塞首版的范围

- 游戏压缩包管理不考虑；GalGear 不内置光盘挂载或安装流程。
- 收藏、时长统计、导入导出、差分补丁、自动更新、版本间关联、作品分组、持久化下载队列、断点续传、下载历史暂缓。
- 内置 CG／回想解锁取消，不新增引擎或执行其效果验收；清理残留的桌面能力属于 R14。

实现顺序沿用游戏整理与启动优先于补丁管理：先完成界面、条目、资料、标签及运行检测，继而存档快照／历史与工具接入，再完成补丁历史目标及下载收尾，最后对完整发行包验收与发布。排序不豁免任何首版必需项。
