# 游戏页实现设计

2026-10-14，依据已确认的 library-page-requirements.md。

沿用 GalGear 的花形标识、粉紫色和完整竖向封面。唯一强调区是标题下方的悬浮工具栏：统计放左侧，搜索及后续控件固定在右侧，搜索向左展开；批量操作切换同一条栏为偏紫的选择状态。海报保持完整，失效提示放在名称旁，收藏夹用文件夹卡片及面包屑表达层级。

基础色：页面粉白 #FBF7FA、工具栏浅玫瑰 #F7EBF2、选中淡紫 #EEE7FA、主色莓粉 #B84479、正文深紫灰 #493C4C、危险红 #BA4256。实际样式复用现有亮暗主题变量。字体沿用本地中文系统字体及应用 14/16/18px 设置，工具栏采用紧凑而完整的文字控件，标题和游戏名左对齐。

布局：左侧为纯图标的纯导航 Tabs；右侧收藏夹页面内仅展示当前层级的用户文件夹卡片，初始为空，目录内容为固定“收藏夹”标题 → 可点击收藏夹层级路径 → 专用工具栏 → 文件夹与当前收藏夹内游戏卡片。完整单排优先，提高最小尺寸，并由桥接层测量实际工具栏宽度约束原生窗口。标签编辑只在详情，管理弹窗使用焦点约束与 Escape 退出。

```text
游戏入口   | 收藏夹专用工具栏／文件夹卡片（右侧内容区）
收藏夹入口 | 当前收藏夹标题          [编辑]
           | 主页 / 系列 / 第一部
           | [库数 游戏数] [向左展开的搜索] [标签] [排序] [刷新] [添加] [批量]
           | [子收藏夹入口] [封面] [封面] [封面]
```

对照简报复核：取消独立统计卡、页脚计数和第二条标签工具栏，避免把游戏封面页改成仪表盘；保留既有美术与详情页，不增加通关、时长或示例资料。批量模式采用同栏切换，区别于参考图中的常驻开关和第二排操作。

最新交互以 requirements.md 第 18 至 23 节为准。保留粉紫主题及完整封面，改进侧栏入口、右击菜单、弹窗标签筛选、搜索图标收放与批量框选；设置采用第二列分类导航和右侧内容卡片；详情切换统一原位编辑模式，只有页面右上角编辑／保存入口。标签筛选采用搜索添加、多选 tag 取消叉与右下角确认按钮，工具栏右侧 × 支持即时清除全部标签筛选。详情页的制作人员及制作组 tag 直接打开游戏库筛选。待确认游戏采用可滚动的多行列表，逐行独立配置后统一保存；主动刷新重新提示未匹配的游戏。
